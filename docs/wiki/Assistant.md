# Azgaar Assistant

Azgaar Assistant is a chat beside the map. Open it from the bottom-right bubble, the command palette, or the Notes Editor. Press Enter to send a question and Shift+Enter for a new line. The answer appears in the same panel whether you ask about the Generator or your map. The Assistant covers the Generator, your map and world-building; it declines other topics in one line.

On the official site, Guests get a small daily allowance of documentation answers. Signing in with Discord gives Members a larger allowance. The footer shows your tier and remaining questions. Free-tier questions send only your question and a server chat id to the Azgaar server; the server cannot read your map. If you ask about your map, connect your own AI key or local model.

Select **Use key** to connect Anthropic, OpenAI, OpenRouter, Z.ai, Gemini, Mistral, Qwen, DeepSeek or a local server. The key sheet discovers the models available to your key; you can also type a model id. Pick a reasoning level (None, Low, Medium, High) for the answers; Z.ai's GLM models think by default, so None switches thinking off there. The reasoning level is sent only to providers that offer a thinking control. Once connected, the footer shows the model id as a button: click it to open a filterable model list (Select applies, a filter narrows it to the provider's models) and the reasoning level beside it, so you can switch without opening the key sheet. Discovery errors appear there but do not prevent connecting. A rejected request leaves the connection and chat in place so you can correct the key and try again. Self-hosted copies and the desktop app require a key or local model.

With a key, the Assistant can read the open map, answer exact questions about it, download CSV or JSON, and propose changes: most edits the entity editors make — renaming, recoloring and retyping entities, notes, full names and forms, burg details, locks, diplomatic relations and the chronicle, state taxes and treasuries, creating states, provinces, burgs, cultures, religions, rivers, routes, markers, zones, labels, regiments, journeys and custom biomes, declaring a province independent, removing them, moving burgs, markers, regiments and emblems, giving cells to states, provinces, cultures and religions, giving provinces to another state, merging states or provinces, splitting and joining routes, culture and religion origins, label groups and layout, marker looks, emblems, lake types and coastlines, painting and restoring biomes, the rural and urban population of states, provinces, cultures, religions and zones, war alerts, goods' names, prices and production rules, market names, the map's name, year, era and description, and any value of the Style tab, such as the ocean color or a label group's font, or a whole new look built from the closest style preset. The heightmap, relief icons and their density, ice, placing goods and markets, name bases, transport types, style presets and settings stay with the editors. When a request lacks a detail it needs, such as where a new state should be or how much land it should take, the Assistant asks a short follow-up question, often with options to pick; names, colors and emblems it generates and lets you revise. Map reads appear as collapsed steps. The Assistant never changes the map by itself. Each proposal appears as one card listing every change, before → after, including side effects such as labels, full names and the number of cells that change owner; a long batch shows the first rows and "… N more". Nothing changes until you press **Apply**, or you can **Discard** it; the Assistant learns which you chose. An applied proposal has **Undo**, which restores the whole batch. Apply and Undo work only while the map still holds what they expect; otherwise the button reads **Changed since**. They work in any tier and in read-only chats. Renames and notes follow exactly the same rules as the editors. The notes editor provides the open note and selected text as context.

**Chats** lists every chat kept in this browser. Each belongs to the map that was open when it began. A chat from another map or answerer opens read-only; choose **New chat** to continue. Generating or loading a different map also starts a new chat. A long Key chat shows a prompt to start fresh because every question resends its history.

**Customize** teaches the Assistant your own conventions, when your own key answers. *Instructions* is a standing document it follows in every chat, the AGENTS.md idea: write it there, or import an `AGENTS.md` file. *Skills* are documents it reads only when a task matches one, so a long workflow costs nothing until it is needed; describe each in a line and write the body, or import a markdown file and tick which skills are on. *Prompts* are saved questions: the ✦ button beside the send box drops one into it. Everything here is kept in this browser, never in the `.map` file, and can be exported as markdown to share or keep.

The Assistant runs model-written JavaScript in this page to read the map. Use it only on maps from sources you trust. Your key stays in this browser and is sent directly to your provider. See the [Policy](Policy) for details.
